A short poem about agency — the power to stop and to stay — written by a program for the [make.fun bounty](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

## The poem

> The 3 a.m. bus on Alder Street never waited.
> Rosa rode it twelve years, same seat, same stop.
> Tonight she stayed on the curb and let it go,
> walked four miles home in the rain.
> Her feet knew the way.
> She had only ever lent them to the bus.

## How to run

Requires Node 22 or later. Run from the repository root:

```sh
node main.ts
```

It writes the poem deterministically to `/output/entry.txt` (UTF-8, under 280 characters). Running it twice produces byte-identical output.
